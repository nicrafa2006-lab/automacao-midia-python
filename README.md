#  Automação de Mídia com Python

Este projeto foi desenvolvido para facilitar a gestão de grandes bibliotecas musicais. Ele automatiza a conversão de arquivos de vídeo para áudio e organiza a estrutura de pastas automaticamente.

##  Tecnologias
- **Python 3.x**
- **MoviePy** (Processamento de vídeo)
- **OS / Shutil** (Manipulação de arquivos do sistema)

##  Como funciona
1. O script varre o diretório de origem em busca de arquivos `.mp4`.
2. Converte cada arquivo para `.mp3` mantendo a qualidade.
3. Move os arquivos finais para pastas organizadas por nome de artista.
4. Remove os arquivos originais para economizar espaço em disco.
